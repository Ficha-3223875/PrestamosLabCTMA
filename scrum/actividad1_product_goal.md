# Actividad 1 - Descubrimiento y Product Goal

## Proyecto: PréstamoLab CTMA

### 1. Problema

Actualmente, el proceso de préstamo de equipos y herramientas del CTMA requiere
un mejor control de la disponibilidad de los elementos, las solicitudes realizadas
y el seguimiento de los préstamos.

PréstamoLab CTMA busca apoyar este proceso mediante una aplicación móvil que
permita organizar y consultar la información relacionada con los préstamos.

### 2. Usuarios

Los principales usuarios del sistema son:

- Aprendices que necesitan consultar y solicitar equipos o herramientas.
- Personal encargado de gestionar y controlar los préstamos.

### 3. Necesidades

Los usuarios necesitan:

- Consultar los equipos y herramientas disponibles.
- Conocer la disponibilidad de cada elemento.
- Realizar solicitudes de préstamo.
- Consultar el estado de las solicitudes.
- Facilitar el seguimiento de los préstamos realizados.

### 4. Restricciones

- La solución será desarrollada como una aplicación móvil Android.
- El proyecto se desarrollará utilizando Android Studio.
- Se utilizará Kotlin para el desarrollo de la aplicación.
- El trabajo se realizará de forma incremental aplicando Scrum.
- Se utilizará Git para el control de versiones del proyecto.
- Las funcionalidades desarrolladas deberán ser verificadas mediante pruebas.

### 5. Valor esperado

PréstamoLab CTMA permitirá mejorar la organización del proceso de préstamo de
equipos y herramientas, facilitando a los aprendices la consulta y solicitud de
elementos y permitiendo un mejor seguimiento de las solicitudes.
