# Definition of Done

1. El proyecto compila y se ejecuta en el ambiente definido.
2. Los criterios de aceptación seleccionados están implementados.
3. La UI representa `UiState` y no modifica directamente la fuente de datos.
4. El ViewModel expone `StateFlow` de solo lectura.
5. La navegación transporta `equipoId`/`solicitudId` y maneja IDs inexistentes.
6. Los 18 casos tienen resultado real PASS/FAIL/BLOCKED o una justificación de bloqueo.
7. Los defectos altos/críticos tienen decisión explícita.
8. Toda corrección relevante tiene confirmación y regresión cuando aplica.
9. Git/README/documentación están actualizados y sin secretos ni archivos generados innecesarios.
10. El incremento puede demostrarse y cada integrante puede explicar decisiones técnicas y de calidad.
