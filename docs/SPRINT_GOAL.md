# Sprint Goal — PréstamoLab CTMA

## Objetivo del Sprint

Consolidar y validar el incremento funcional de PréstamoLab CTMA, asegurando que el catálogo de equipos, la consulta de detalles y el proceso de solicitud de préstamo funcionen correctamente y cumplan sus criterios de aceptación.

## Resultados esperados

- Consultar el catálogo de equipos.
- Consultar el detalle de un equipo.
- Mostrar la disponibilidad del equipo.
- Registrar solicitudes de préstamo.
- Validar los datos antes de registrar.
- Evitar solicitudes duplicadas.
- Consultar las solicitudes del usuario.
- Permitir cancelar solicitudes en estado `SOLICITADA`.
- Buscar equipos.
- Filtrar equipos por categoría.
- Manejar equipos y solicitudes inexistentes sin cierre inesperado.
- Mantener una arquitectura organizada con Compose, ViewModel, UiState, StateFlow y Repository.
- Contar con pruebas automatizadas y controles de calidad.

## Criterio de cumplimiento

El Sprint Goal se considera cumplido cuando las funcionalidades implementadas cumplen sus criterios de aceptación, las pruebas automatizadas son exitosas y existen evidencias reproducibles del funcionamiento.
